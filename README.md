# Tiger Stop

Raja's Roadhouse — a roadside RTS built with Godot 4.7 and exported for the web.

**Play now:** https://xrecessive.github.io/tiger-stop/

Run a 24-hour diner, a diesel & wrench bay, and a fuel canopy while keeping Raja the tiger fed, clean, and happy. A happy tiger pulls truckers off the highway; a hungry one starts looking at the gate.

## Goal

Finish Day 10 with **$5,000** cash and **reputation 60+**, with Raja alive and contained.

## Controls

| Input | Action |
| --- | --- |
| Click a building | Select diner / garage / pumps |
| Click the tiger pen | Feed Raja |
| `Enter` | Start the shift |
| `Space` / `Esc` | Pause / resume |
| `1` `2` `3` | 1x / 2x / 4x speed |
| `F` `P` `C` `V` | Feed / Play / Clean / Vet |
| `Tab` | Cycle stations |
| `M` | Mute |

## Hosting

This repository contains only the exported web build, published with GitHub Pages from `main / (root)`.
The Godot source project is not in this repository.
